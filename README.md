# Calculator

A basic calculator built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Responsive and simple user interface
- Interactive calculator buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Description

This project is a functional web-based calculator designed to perform basic arithmetic operations. It uses JavaScript to handle calculations and user interactions, with HTML and CSS used to create the structure and design.
